# A-Spadz Impact partner emails

Standalone HTML email templates and image assets for the A-Spadz affiliate/partner program.

The assets are intentionally hosted outside Windhorse Shopify. The HTML templates use the
public jsDelivr URL for this repository:

`https://cdn.jsdelivr.net/gh/golivestores/aspadz-impact-emails@main/assets/`

Templates:

- `emails/aspadz-application-received.html`
- `emails/aspadz-not-approved.html`
- `emails/aspadz-welcome.html`

Before production use, import each template into Impact and send a real test email. Confirm
the platform's unsubscribe variable and replace it where marked in the footer.
