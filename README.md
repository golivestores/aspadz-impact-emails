# A-Spadz Impact partner emails

The three HTML emails in `emails/` reproduce the supplied 600px designs using precisely
aligned image strips. Email, button, social, and policy areas have separate links. Images are
served from this repository through jsDelivr at the immutable `v1.0.0` tag.

Image URL base: `https://cdn.jsdelivr.net/gh/golivestores/aspadz-impact-emails@v1.0.0/assets/v2/`

Before enabling these emails in Impact, send a test for each application state and confirm
the platform's unsubscribe handling. The public HTML files are templates, not an active
Impact configuration.

The visual body is image based to preserve the supplied designs exactly. If the recipient's
email client blocks remote images, image alternative text is the fallback.
